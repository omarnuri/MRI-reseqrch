# spinelab — анализ МРТ позвоночника (исследовательский)

> **Не диагноз.** Инструмент считает измерения по маскам открытых сегментационных
> моделей и показывает, где они расходятся между сторонами и уровнями. Всё это
> требует проверки врачом-рентгенологом на исходных изображениях. Часть этапов —
> эвристики по яркости пикселей; в отчёте они помечены отдельно и находками не
> являются.

## Быстрый старт (Google Colab, слабый интернет учтён)

Открыть `notebooks/colab_pipeline.ipynb` в Colab, Runtime → GPU, выполнить 4 ячейки:

1. смонтировать Drive и указать каталог кэша весов;
2. поставить окружение (идемпотентно, ядро не перезапускается);
3. запустить пайплайн (продолжается с места обрыва);
4. посмотреть отчёт.

DICOM-архив кладётся **в Drive**, не в репозиторий (см. [docs/PRIVACY.md](docs/PRIVACY.md)).

## Локально / из командной строки

```bash
python -m spinelab run --dicom /path/study.zip --cache ~/spinelab-cache
python -m spinelab run --dicom /path/study.zip --quality --tta-mirror   # 24+ ГБ VRAM
python -m spinelab run --only marrow,posterior,report --force marrow
python -m spinelab inspect --dicom /path/study.zip  # список серий, без GPU и dcm2niix
python -m spinelab audit --dicom /path/dicom       # какие PHI-теги есть в заголовках
python -m spinelab deid  --dicom /path/dicom --out /path/anon
python -m spinelab stages                          # список этапов
```

Тесты (без GPU и без данных, ~1 с):

```bash
python -m pytest -q
```

## Что делает пайплайн

| Этап | Инструмент | Что даёт | Уровень |
|---|---|---|---|
| `ingest` | dcm2niix | NIfTI, инвентарь серий, выбор последовательностей, PHI-аудит | измерение |
| `spineps` | SPINEPS 2.0 (+ VERIDAH labeling) | тела позвонков, **задние элементы по сторонам**, нумерация | модель |
| `totalspineseg` | TotalSpineSeg | спинной мозг, канал, диски по уровням | модель |
| `totalsegmentator` | TotalSegmentator MRI | параспинальные мышцы, рёбра | модель |
| `register` | SimpleITK | совмещение масок с fat-sat и аксиальной серией (поправка на движение) | измерение |
| `fatsat_qc` | — | работает ли подавление жира; гейт для всей ветки про отёк | эвристика |
| `crosscheck` | TotalSegmentator `vertebrae_mr` | согласие двух независимых моделей по уровням (профиль quality) | модель |
| `facets_axial` | — | фасеточные суставы по уровням и сторонам на аксиальной T2 | эвристика |
| `geometry` | — | высоты тел, углы клиновидности, правило Шейермана, кривизна | измерение |
| `muscles` | — | объём и лево-правая асимметрия мышц | измерение |
| `marrow` | — | неоднородность сигнала в телах позвонков (**только при fat-sat**) | эвристика |
| `posterior` | — | сравнение левых и правых фасеточных / поперечных отростков | эвристика |
| `canal` | — | профиль площади канала, относительное сужение | измерение |
| `discs` | — | относительный сигнал дисков по уровням | измерение |
| `radiomics` | — | first-order + GLCM по телам позвонков | измерение |
| `agreement` | — | Dice спинного мозга между двумя сегментаторами (контроль) | измерение |
| `report` | — | один HTML-отчёт + `findings.json` | — |

Каждый этап пишет `results/stages/<этап>.json`. Повторный запуск читает их и
продолжает с места обрыва — Colab на слабом канале отваливается регулярно.

## Что известно про это исследование

`spinelab inspect` по реальному архиву: сагиттальные T2 и T1 (17 срезов, 3.5 мм),
коронарный STIR (23 среза, 4 мм, TI 100 мс — единственная серия с подавлением жира),
**аксиальная T2 (66 срезов, 4 мм, 0.49 мм в плоскости)** и разметочный скаут.
Сканер 1.5 Тл.

Аксиальная серия — самая информативная в исследовании и единственная плоскость, в
которой грудные фасеточные суставы разрешимы; старый ноутбук её не использовал ни
для чего. Отёк оценивается только по коронарному STIR, и только если проверка
`fatsat_qc` подтвердит, что жир действительно подавлен.

## Главное ограничение

Без последовательности с подавлением жира (STIR / TIRM / SPAIR / Dixon) отёк
костного мозга и периартикулярный отёк **не оцениваются** — и пайплайн в этом
случае отказывается выдавать числа, а не выдаёт их с оговоркой. Без аксиальной
(или косой) плоскости грудные фасеточные суставы почти не видны. Подробно —
[docs/clinical-context.md](docs/clinical-context.md).
