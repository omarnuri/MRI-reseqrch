## Порядок действий (по приоритету)

**1. Сделать репозиторий приватным — прямо сейчас, это одно действие.**
Settings → General → Danger Zone → Change repository visibility → Private.
Это не удаляет данные из истории, но останавливает дальнейшее распространение и
даёт время на остальное.

**2. Убрать архив из истории, а не из последнего коммита.**
Удаление файла обычным коммитом бесполезно: blob остаётся доступен.
Нужен `git filter-repo` (рекомендуемый инструмент, `git filter-branch` устарел):

```bash
git filter-repo --path "OMER_NURIYEV (RAMIN)_dcm_8be27145-5512-4999-bb34-7e92b5f69749 (1).zip" --invert-paths
```

Затем force-push всех ветвей и тегов. После этого **обязательно** открыть тикет в
GitHub Support с просьбой удалить кеш и висячие объекты — до этого blob всё ещё
достаётся по прямой ссылке. Все форки (если есть) надо удалять отдельно: они
остаются с полной историей.

**3. Перенести данные в Google Drive.**
Пайплайн ожидает путь на Drive (`--dicom /content/drive/MyDrive/mri/study.zip`) —
именно потому, что данным не место в репозитории. Repo содержит только код.

**4. Хранить деидентифицированную копию для экспериментов.**

```bash
python -m spinelab audit --dicom /path/to/dicom      # что вообще есть в заголовках
python -m spinelab deid  --dicom /path/to/dicom --out /path/to/anon
```

`audit` печатает список найденных идентифицирующих тегов и вердикт; пайплайн
сохраняет его в `results/phi_audit.json` при каждом прогоне.
`deid` пишет копию, где прямые идентификаторы очищены или заменены,
private-теги удалены, выставлены `PatientIdentityRemoved=YES` и
`DeidentificationMethod`.

**Границы `deid` — читать обязательно:** это подмножество профиля
DICOM PS3.15 Basic Application Level Confidentiality, а не сертифицированная
деидентификация. Не обрабатываются: текст, «вжжённый» в пиксели (burned-in
annotations), нестандартные приватные теги отдельных вендоров, имена файлов и
каталогов. Для публикации данных этого недостаточно; для работы в Colab —
достаточно, чтобы не тащить ФИО в облако.

**5. Очистить выводы ноутбука перед любым коммитом.**
`notebooks/legacy/spine_analysis_pipeline.ipynb` хранится с выводами. Если он
когда-нибудь пойдёт в публичный репозиторий — сначала `jupyter nbconvert
--clear-output --inplace`. Новый `notebooks/colab_pipeline.ipynb` хранится без
выводов; так и надо оставить.

## Что уже сделано в коде

* Данные читаются из произвольного пути (Drive), репозиторий больше не является
  источником данных: клонирование в Colab идёт `--filter=blob:none --sparse` и
  архив не скачивается вообще.
* Отчёт не печатает ни имён файлов исследования, ни accession number, ни ФИО —
  только `subject_id`, который задаёте вы (по умолчанию `anon`).
* `dcm2niix` вызывается с `-ba n`, то есть сайдкары **не** анонимизируются: это
  сделано осознанно, чтобы аудит PHI видел правду. Значит сайдкары нельзя
  публиковать — они лежат только в рабочем каталоге Colab.
* `.gitignore` закрывает `*.zip`, `*.dcm`, `*.nii`, `*.nii.gz`, `results/`.
