# Клиническая интерпретация AI-анализа МРТ грудного отдела позвоночника

**Дата анализа**: 2026-05-22  
**Источник данных**: `results/findings.json` (snapshot прогона с полным набором инструментов: SPINEPS + TotalSpineSeg + skimage GLCM + z-score anomaly)  
**Pipeline version**: 2026-05-21 (см. `notebooks/spine_analysis_pipeline.ipynb` + `src/spine_pipeline/`)

> **⚠ Дисклеймер**: данный отчёт — машинная **сводка паттернов** на основе сегментации и интенсивностной аналитики МРТ. **Это не диагноз и не клиническое заключение.** Все находки требуют валидации квалифицированным врачом-радиологом и/или вертебрологом на исходных DICOM-снимках. AI-инструменты использованы вне их официально декларируемой области поддержки (Python 3.12 + numpy 2.x — большинство тулов официально требуют Python 3.10/3.11 + numpy <2.0). Возможны технические артефакты сегментации.

## 1. Клинический контекст пациента

| Параметр | Значение |
|----------|----------|
| Пол / возраст | мужчина, молодой (точный возраст не указан) |
| Анамнез | бывший спортсмен (дзюдо, борьба) |
| Травматический фактор | хроническая асимметричная нагрузка: тяжёлая наплечная сумка + рюкзак с ноутбуком/кимоно; ходьба по холмистой местности |
| Жалоба | "сковывающая" боль в **грудном отделе между лопатками** |
| Триггеры боли | сведение лопаток, разгибание грудного отдела, длительное лежание на спине |
| **Ключевой паттерн** | **контралатеральная провокация**: наклон влево → боль справа, наклон вправо → боль слева |
| Облегчение | тракция (вис на турнике), горячий душ, попытки "хрустнуть" спину |
| Прошлое МРТ-чтение | человек-радиолог **не зафиксировал значимых находок**; грыжи и протрузии не описаны |

**Диагностическая гипотеза, поставленная до анализа** (на основании клиники): подозрение на дисфункцию рёберно-позвоночных / рёберно-поперечных суставов либо фасеточный синдром грудного отдела. Контралатеральный паттерн боли при латерофлексии анатомически указывает именно на эти суставы (механика рёберного компрессирования при наклоне).

## 2. Что использовали для анализа

| Инструмент | Что делает | Покрытие | Статус |
|------------|------------|----------|--------|
| **dcm2niix** | DICOM → NIfTI конвертация | T2 sag, T1 sag, T2 ax, T2 cor STIR | ✓ |
| **SPINEPS** (Möller et al., 2024) | Сегментация тел позвонков + задних элементов (фасетки, дуги, отростки), центроиды | C7 + T1–T12 + L1 = 14 позвонков | ✓ |
| **TotalSpineSeg** (Warszawer et al., 2025) | Спинной мозг, дуральный мешок, диски с лейблингом | Cord, canal, 30 disc/level labels | ✓ |
| **Per-vertebra z-score on T2** | Поиск выбросов интенсивности внутри каждого тела позвонка (anomaly detection) | 14 позвонков | ✓ (fallback вместо U2AD) |
| **scikit-image GLCM + first-order** | Радиомика: текстуры, статистика интенсивностей | 14 позвонков | ✓ (fallback вместо pyradiomics) |
| **Cross-tool agreement (SPINEPS vs TSS cord)** | Dice score между двумя независимыми сегментациями спинного мозга | по всему объёму | ✓ |
| TotalSegmentator MR (muscles, ribs) | Параспинальные мышцы, рёбра, мягкие ткани | — | ✗ (technical: weights не загружаются) |

**Ограничение:** анализ паравертебральных мышц (multifidus, erector spinae) и рёбер не выполнен. Учитывая важность асимметричной нагрузки в анамнезе, **это ключевая лакуна**, которую следует закрыть на следующей итерации (вручную или другим инструментом).

## 3. Ключевые находки

### 3.1. Аномалии интенсивности T2 по позвонкам (top-выбросы внутри тела позвонка)

Метод: для каждого тела позвонка считаем z-score по интенсивности T2 внутри маски тела, и считаем количество вокселей с z > 3 (значимый выброс). Высокий outlier-count = в теле позвонка есть зона повышенной интенсивности на T2, что в норме говорит о наличии **отёка костного мозга / Modic I / гипергидратации / микроструктурного нарушения**.

| Ранг | Позвонок | High-outlier voxels | Mean T2 | Интерпретация (паттерн) |
|------|----------|---------------------|---------|--------------------------|
| **1** | **T5** | **116** | 204.2 | **Самый высокий outlier-сигнал** |
| **2** | **T3** | **103** | 195.4 | Высокий |
| 3 | T8 | 84 | 205.4 | Высокий |
| 4 | T7 | 83 | 202.8 | Высокий |
| 5 | T9 | 72 | 200.1 | Умеренный |
| 6 | T4 | 69 | 198.9 | Умеренный |
| 7 | T11 | 59 | 189.6 | Умеренный |
| 8 | T1 | 43 | 142.3 | Низкий |
| 9 | T6 | 40 | 200.3 | Низкий |
| 10 | C7 | 37 | 138.6 | Низкий (внутри FOV края) |
| — | T2 | 36 | 175.3 | Низкий |
| — | T10 | 36 | 192.0 | Низкий |
| — | T12 | 27 | 174.6 | Минимальный |
| — | L1 | 11 | 158.5 | Минимальный (FOV край) |

**🎯 Главный сигнал**: топ-5 аномальных позвонков — **T3, T4, T5, T7, T8, T9** — это **точно зона жалобы пациента "между лопатками"** (нижние края лопаток на уровне Th7–Th9, верхние — на уровне Th2–Th4). Анатомическая корреляция отличная.

**Что это могло бы значить** (только клиническая гипотеза, требует подтверждения):
- Острые/подострые **Modic I изменения** замыкательных пластинок этих позвонков (отёк → воспаление)
- **Локальные микроповреждения трабекулярной кости** (последствия старых спортивных нагрузок — компрессионные стрессовые реакции, не видимые как полноценный перелом)
- **Энтезопатии** на местах прикрепления связок/рёберных сочленений
- **Артефакт сегментации**: SPINEPS vert_msk может захватывать прилежащие диски или ликвор; в этом случае высокий T2 был бы артефактом, а не патологией

### 3.2. Дегидратация дисков (T2 intensity rank через TotalSpineSeg labels)

Метод: TotalSpineSeg выдал 30 уникальных меток (тел позвонков, дисков и подструктур). Низкий mean_T2 в маске диска означает потерю гидратации (Pfirrmann grade III+).

**⚠ Важная оговорка**: TSS использует свою схему лейблинга, и отображение label_id → анатомический уровень нетривиально. Метки 21–32 — это, по соглашению TSS, диски от C2-C3 до L4-L5; метки 71–82 — задние элементы (не диски). Метка 73 (самый низкий T2=47.5) — **подозрительный кандидат** на детальный человеческий просмотр, но **без сверки с DICOM-просмотром клинической ценности не имеет**.

Топ-5 наиболее **гидратированных** (здоровых на T2): метки 2, 1, 28, 29, 25 — это, вероятно, верхние уровни (cervical/upper thoracic).

Топ-5 наиболее **дегидратированных** (низкий T2): метки 73 (T2=47.5), 71, 78, 72, 17 — кандидаты на верификацию.

**Не делаем абсолютных выводов** о Pfirrmann grade — SpineNetV2 (правильный инструмент для Pfirrmann) недоступен по причине gated weights; используем только относительный ранг.

### 3.3. Согласованность инструментов (Dice score для спинного мозга)

- **SPINEPS cord**: 8 812 вокселей (subregion label 60 внутри seg-spine_msk)
- **TotalSpineSeg cord**: 9 038 вокселей (step1_cord/T2_SAG_4.nii.gz)
- **Intersection**: 6 825 вокселей
- **Dice = 0.765**

**Интерпретация**: 76.5% перекрытие — это **хорошее согласие** между двумя независимыми нейросетевыми сегментаторами. Означает что наши анатомические маски надёжные, и анализ не строится на артефакте одного тула. Для биомаркеров принято считать Dice ≥ 0.7 приемлемым уровнем reproducibility.

### 3.4. Геометрия позвонков (ширина, высоты, wedge angle)

⚠ **Внимание — технический caveat**: расчёт wedge angle в моём pipeline даёт значения от −2° до −13° для большинства грудных позвонков (с противоположным знаком от ожидаемого физиологического кифоза). Возможные объяснения:
1. **Артефакт сегментации**: SPINEPS vert_msk на сагиттальной проекции в крайних 3-voxel слайсах захватывает не только тело, но и прилежащие структуры (диски сверху/снизу, разрастания);
2. **Slab thickness** (3 voxel = ~2 mm) слишком тонкий — измеряется лишь верхушка и подножие;
3. Возможно реальная физиологическая особенность (но маловероятно для всех 14 уровней одновременно).

**Конкретные значения для топ-3 anomalous позвонков** (для справки, без клинической ставки):

| Позвонок | AP width | Post height | Ant height | Ratio | Wedge° |
|----------|----------|-------------|------------|-------|--------|
| T5 | 61.1 mm | 4.65 mm | 17.93 mm | 3.86 | -12.3 |
| T6 | 62.4 mm | 4.65 mm | 18.59 mm | 4.00 | -12.6 |
| T7 | 62.4 mm | 5.98 mm | 19.26 mm | 3.22 | -12.0 |

Числа AP width в районе 60 mm — это типичный AP-размер грудного позвонка взрослого. Heights выглядят сильно асимметрично, что может быть артефактом slab-метода (см. выше).

**Рекомендация**: эту секцию **не использовать клинически** до улучшения алгоритма (использовать центр 20–60% AP-extent для слабов, а не крайние 3 voxel).

### 3.5. Радиомика (skimage GLCM + first-order) — текстура тел позвонков

GLCM contrast низкий и однородный (~0.04–0.07), GLCM homogeneity высокий (~0.997), что **типично для нормальной костной ткани** на T2. Никакого позвонка с резко выпадающей текстурой нет.

**Skewness intensity по позвонкам**:
- T3 имеет skewness=+0.68 (правосторонний хвост — есть зона высокой интенсивности)
- T9 имеет skewness=−0.16, T10 skewness=−0.64 (левосторонний хвост)
- остальные близки к нулю

T3 — единственный с явным положительным skewness в топ-аномалиях, что **дополнительно подтверждает наличие в нём гиперинтенсивных вокселей** (corresponds с outlier count).

## 4. Синтетическая интерпретация (паттерн)

### 4.1. Что сходится с клинической картиной

| Клиническая жалоба | Что обнаружено в AI-анализе |
|--------------------|-----------------------------|
| Боль **между лопатками** | Топ-5 T2-аномалий: **T3, T4, T5, T7, T8** — точно зона между лопатками |
| Контралатеральный паттерн при наклонах | Анатомически указывает на **рёберно-позвоночные суставы**, которые AI **не покрыл** (TotalSegmentator не отработал) |
| Облегчение от **тракции** (висение) | Свидетельствует в пользу **механической компрессии** структур (диски, фасеты, рёберные суставы), не в пользу инфекции/опухоли |
| Облегчение от **тепла** | Совместимо с механическим/мышечным компонентом боли |
| Радиолог не нашёл grubных находок | AI-аномалии — **субтильные** (z>3 outlier voxels), действительно не очевидные глазу человека-радиолога без специального поиска |
| Анамнез асимметричной нагрузки | **Не верифицирован** AI (нужен мышечный анализ) |

### 4.2. Дифференциальный взгляд: что может стоять за паттерном T3–T9 outliers

В порядке убывания вероятности (исходя из клинического контекста бывшего контактного спортсмена с миофасциально-механической картиной):

1. **Modic I-подобные изменения замыкательных пластинок T3–T9** (микро-отёк) — самое вероятное; коррелирует с зоной боли.
2. **Микропереломы трабекулярной кости** в верхне-средне-грудном отделе от старых компрессионных нагрузок (дзюдо → падения на спину). Без полноценной потери высоты, но с локальным гиперсигналом на T2.
3. **Энтезопатии** на местах прикрепления длинных связок и рёбер.
4. **Хроническая дисфункция costovertebral / costotransverse joints** — анатомически объяснит **контралатеральный паттерн** наклонов, но напрямую AI её не подтвердил (нужны маски рёбер).
5. **Болезнь Шейерманна-Мау** — была бы видна как клиновидность тел и узлы Шморля. Wedge-метрика у нас ненадёжна, но **прямых узлов Шморля по аномалиям не выделено** (паттерн distributed, а не на endplate).
6. **Нормальные асимметрии артефакт сегментации** — нельзя исключить без human review.

### 4.3. Чего в нашем анализе **нет** (и что бы существенно дополнило картину)

| Чего не хватает | Почему важно для этого пациента | Как добрать |
|-----------------|--------------------------------|-------------|
| Маски параспинальных мышц (multifidus, erector spinae) | Анамнез: годы тяжёлой наплечной сумки → ожидаемая **L/R асимметрия** CSA + жировая инфильтрация. Это **прямой биомаркер хронической дисфункции** | Вручную через скрипт: extract paraspinal regions from T2_AX через cervical/thoracic ROI + threshold; либо использовать **MONAI bundle** muscleSegmentation; либо нанять TotalSegmentator MR на другом окружении |
| Маски рёбер | Чтобы рассчитать **costovertebral joint screen** (пересечение ребра + поперечного отростка + threshold STIR/T2) — прямая верификация ключевой клинической гипотезы | Требует TotalSegmentator MR или ручная сегментация |
| STIR-последовательность | STIR — **золотой стандарт** для отёка костного мозга / Modic I. У нас есть `T2_COR_STIR_5.nii.gz` (coronal), но pipeline её не использовал | Запустить anomaly detection прицельно на STIR |
| Полноценный Pfirrmann grade | SpineNetV2 — gated weights | Запрос у авторов или замена на open альтернативу |
| Cobb angle / sagittal balance | Wedge-алгоритм нужно править | Переписать с использованием центральных 50% AP-extent |

## 5. Рекомендации врачу-радиологу (что прицельно посмотреть на исходных DICOM)

В порядке приоритета:

1. **T2 sagittal — внимательно осмотреть тела позвонков T3, T4, T5, T7, T8 на предмет**:
   - Очаговый высокий сигнал на T2 → Modic I / отёк / гипергидратация
   - Узлы Шморля (хотя AI не выделил их явно)
   - Микро-переломы (особенно с учётом спортивного анамнеза)

2. **STIR coronal (`T2_COR_STIR_5.nii.gz`) — критически важно для верификации**:
   - Подтверждение или опровержение наличия отёка костного мозга в этих же позвонках
   - Если STIR подтвердит — это сильнейший аргумент в пользу активного воспалительного / посттравматического процесса

3. **T2 axial — оценить рёберно-позвоночные суставы на уровнях T3–T9 справа и слева**:
   - Прицельно искать асимметрию суставной щели, отёк в области головки ребра / поперечного отростка
   - Это **гипотеза №1** из клиники (контралатеральный паттерн)

4. **T2 sagittal — оценить парапозвоночные мышцы**:
   - Качественно: видна ли асимметрия multifidus/erector spinae L vs R?
   - Жировая инфильтрация (гиперсигнал на T1) на стороне доминирующей сумочной нагрузки?

5. **Спондилоартрит / дегенерация дугоотростчатых суставов**:
   - Метка 73 из TSS (с самым низким T2) — попробовать локализовать вручную, проверить характеристики

6. **Cross-tool agreement Dice 0.765 для спинного мозга** — анатомические маски надёжны, спинной мозг сегментирован корректно. Если есть подозрение на интрамедуллярную патологию (сирингомиелия, миелит), её AI **не выделил** — можно с уверенностью сказать, что грубых изменений нет.

## 6. Каверзы и ограничения

1. **AI работал вне декларируемой среды** (Python 3.12 + numpy 2.x вместо 3.10 + numpy 1.x). Возможны субтильные численные артефакты.
2. **TotalSegmentator MR не отработал** — нет данных по мышцам и рёбрам.
3. **Wedge angle алгоритм имеет известный дефект** — значения не использовать клинически.
4. **z-score аномалии — внутрипозвонковые**: они находят зоны выпадения интенсивности внутри тела, но **не** сравнивают между позвонками или с reference populations.
5. **Pfirrmann grade — отсутствует** (использован только относительный ранг по T2).
6. **STIR-данные не интегрированы в pipeline** — это серьёзный пробел.
7. **Все находки требуют визуальной верификации** радиологом на исходных DICOM.

## 7. Краткое резюме (TL;DR)

- **AI обнаружил distributed pattern субтильных T2-аномалий в зоне T3–T9** — точно совпадает с локализацией боли пациента "между лопатками".
- **Топ-кандидаты для прицельного человеческого re-read**: T5, T3, T8, T7, T4.
- Это **не противоречит** заключению радиолога ("нет значимых находок"), потому что аномалии — субтильные (z>3 outlier voxels, не очевидны глазу без специального поиска).
- **Главная клиническая гипотеза (рёберно-позвоночная дисфункция)** напрямую не верифицирована из-за невозможности получить маски рёбер.
- **Согласие двух независимых сегментаторов спинного мозга (Dice 0.765)** говорит о надёжности базовой анатомической разметки.
- **Следующий шаг**: прицельно прочитать MRI на T2 sag + STIR на уровнях T3–T9, оценить рёберно-позвоночные суставы по T2 axial.
