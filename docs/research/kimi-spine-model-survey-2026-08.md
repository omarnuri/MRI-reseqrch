# Открытые модели и инструменты для автоматического анализа МРТ позвоночника — обзор на август 2026 г.

**Скоуп обзора.** Ищутся только открытые (публично скачиваемые веса, inference-only) модели и инструменты, применимые к имеющемуся протоколу: сагиттальные T2 TSE и T1 TSE 3 мм (in-plane 0,27–0,39 мм), аксиальные T2 TSE 3–3,5 мм, 3D SPACE fat-sat (TE 437 мс, миелографический контраст), корональная STIR; аппараты 1,5 Тл Siemens и FUJIFILM; приоритет — шейный и грудной отделы, поясничный — вторично. Клинические вопросы: фасеточные и реберно-позвоночные суставы, отек костного мозга позвонков (BME), стеноз канала и фораминальный стеноз, состояние дисков, асимметрия параспинальных мышц. Уже установленные в пайплайне компоненты (dcm2niix, SPINEPS 2.0, TotalSpineSeg, TotalSegmentator MRI) не пере-предлагаются, а используются как референс. Ранее отклонённые подходы (U²AD, нетренированный автоэнкодер MONAI, SpineNet/SpineNetV2, BiomedCLIP, MedSAM2, VLM-«второе мнение», pyradiomics) не рассматриваются повторно.

**Проверка.** Версии и даты взяты из PyPI JSON API и GitHub Releases API (не из дат коммитов README); доступность весов проверена прямыми скачиваниями/HEAD-запросами к релизным архивам и HuggingFace API; статус «не проверял» ставится там, где проверка технически не удалась или источник не даёт данных. Всё, что требует обучения, разметки или нормативной когорты, помечено явно и вынесено из списка рабочих кандидатов.

## TL;DR

1. **Из готового к inference реально применим только экосистемный блок Spinal Cord Toolbox (SCT)**: контраст-агностическая сегментация спинного мозга (шейный+грудной отделы — это нативный домен), сегментация дурального мешка на T2, сегментация серого вещества и два калиброванных измерительных модуля стеноза шейного канала — `sct_detect_compression` и `sct_compute_ascor`. Всё с публичными весами без регистрации, всё валидировано именно на шейном/грудном отделах [^23^][^35^].
2. **Градация дисков и фасеточных суставов по шкалам Pfirrmann/Fujiwara с публичными весами существует в единственном экземпляре** — CNN Никпасанда и Эллингсона (веса на DRUM, проверено прямым скачиванием, CC BY-NC-ND), но она **только поясничная, однослойная 2D и требует ручного кропа ROI**; на шейный/грудной отделы без дообучения не переносится [^36^][^46^].
3. **Чего в открытом доступе нет (раздел B)**: сегментации и градации грудных фасеточных и реберно-позвоночных суставов на МРТ; детектора отека костного мозга позвонков без дообучения; открытых нормативных распределений геометрических/текстурных метрик для грудного отдела. Это означает, что соответствующие задачи в одноисследовательском сценарии решаются только геометрией из уже имеющихся масок (SPINEPS/TotalSpineSeg/SCT) плюс порогами из литературы, либо не решаются вовсе.
4. **За 2025–2026 гг. появилось практически значимое**: SCT 7.0–7.3 (детекция компрессии, серое вещество, aSCOR), обновлённые веса канала (r20260406) и контраст-агностической модели (v4.0), TotalSegmentator 2.5.0 с `vertebrae_mr` и `tissue_4_types`, датасеты LSS-MRI-AISSLab (фораминальный стеноз, поясн.) и LSMA-PQR, публикация RSNA-LSDD в открытом реестре AWS и шейный датасет Duke CSpineSeg (через MIDRC, с DUA) [^23^][^89^][^29^].

## Как проверялось

Версии пакетов — из PyPI JSON API (`/pypi/{pkg}/json`, поле `releases` с датами загрузки файлов) и GitHub REST API (`/repos/{owner}/{repo}/releases`); наличие и размер весов — HEAD-запросами к ассетам GitHub Releases, HuggingFace Hub API (`/api/models/{id}`, поля `gated`, `usedStorage`, `lastModified`) и прямым скачиванием с DSpace 7 REST API репозитория DRUM (Университет Миннесоты) с распаковкой и инвентаризацией содержимого. Утверждения о назначении моделей взяты из README/кода upstream-репозиториев и первичных публикаций, а не из обзоров; расхождения «статья против репозитория» отмечены отдельно. Там, где запрос к ресурсу из песочницы не удался (таймауты HuggingFace для ряда страниц, недоступность отдельных лендингов), статус честно помечен «**не проверял**» — эти пункты требуют ручной перепроверки перед использованием, и в отчёте они не считаются доступными.

Критерии включения в раздел A-1 (рабочие кандидаты): (а) веса скачиваются публично, без e-mail-запросов, подписания соглашений и gated-доступа; (б) модель работает в режиме inference на мономодальных МРТ-данных без дообучения; (в) заявленная область применения подтверждается обучающими данными upstream-источника. Модели, не прошедшие хотя бы один критерий, собраны в разделе A-4 с явной причиной отказа — это сделано, чтобы таблица кандидатов не смешивала «готовое» с «потенциально возможным после обучения».

Два уточнения к таблице 1, которые важны для интерпретации. Во-первых, контраст-агностическая модель спинного мозга SCT — единственный инструмент из списка, чья валидация по построению включает шейный и грудной отделы, разных вендоров и патологические когорты: статья Bédard 2025 (Medical Image Analysis) прямо описывает обучение на Spine Generic (n=267, шесть контрастов) с мягкой разметкой и тестирование на когортах с миелопатией, рассеянным склерозом и внутримозговыми опухолями [^16^]. Для вашего протокола это означает, что маски спинного мозга и канала на сагиттальных T2 TSE и 3D SPACE получаются без всякой адаптации, а геометрия стеноза затем считается измерительными модулями (раздел A-2). Во-вторых, `sc_canal_t2` обучался на клинических T2w-исследованиях с active learning, и его применимость к миелографическому 3D SPACE fat-sat (TE 437 мс, где видна только жидкость) правдоподобна по контрасту, но отдельно нигде не верифицирована — это честный кандидат на «потратить пару GPU-часов и посмотреть маску», тем более что сама модель уже скачивается без регистрации [^33^].

Отдельно отмечу расхождение «статья против репозитория» у SAM-Med3D: публикация описывает универсальную promptable-сегментацию по 21+ типу структур с акцентом на опухоли и органы, но ни в статье, ни в репозитории нет ни одной валидации на суставах, дисках или костном мозге позвоночника [^20^]. Поэтому SAM-Med3D включён в рабочие кандидаты формально (веса публичны, inference-only), но с прямой пометкой «эвристика»: использовать его маски фасеточных суставов или дисков как основание для измерений нельзя, это был бы некалиброванный метод — ровно то, что правилами обзора запрещено. Модель skaliy/fastMONAI оставлена в таблице с пометками «не проверял», потому что HuggingFace-страница из песочницы не открылась; перед любым использованием нужно вручную проверить, не gated ли веса.

Клинический смысл для вашего кейса (межлопаточная боль, боль при движениях шеи) прямой: стеноз шейного канала — единственная из ваших задач, для которой в открытом доступе есть инструмент с внешне валидированными порогами, причём пороги получены именно на клинических 3D T2w-исследованиях, близких по контрасту к вашему 3D SPACE [^69^]. Ограничение тоже надо зафиксировать честно: `sct_detect_compression` покрывает только C3/C4–C6/C7 и не распространяется на грудной отдел — торакальной версии этой модели не существует; aSCOR аналогично шейный. Таким образом «калиброванная» часть пайплайна закрывает только шейный канал, а грудной стеноз останется описательной геометрией (диаметры, площади из масок SCT/TotalSpineSeg без популяционных порогов).

### A-3. Градация дисков и фасеточных суставов с публичными весами (единственный найденный случай)

Единственная пара градационных моделей, чьи веса реально скачиваются без запросов — CNN Никпасанда и Эллингсона из JOR Spine 2024, выложенные в институциональный репозиторий DRUM (Университет Миннесоты). Проверка выполнена не по странице, а прямым скачиванием архива через DSpace 7 REST API и распаковкой: внутри `disc/disc_model.h5` (**44,09 МБ**, 5-классовая шкала Pfirrmann по кропнутому срединно-сагиттальному T2) и `joint/joint_model.h5` (**22,15 МБ**, шкала Fujiwara по кропнутому аксиальному T1), плюс два Jupyter-ноутбука инференса; лицензия записи — **CC BY-NC-ND**, дата финализации записи 25.06.2024 [^36^][^46^]. Обучение выполнено на Lumbar Spine MRI Dataset (515 пациентов, 1,5 Тл Siemens Essenza, уровни L1/2–L5/S1) — то есть **только поясничный отдел**, и никакой валидации на шейном/грудном отделах в первоисточнике нет [^36^].

Три ограничения делают эти модели «вторичным» инструментом в ваших терминах. Во-первых, обе сети двумерные и однослойные: вход — вручную (или полуавтоматически по маскам SPINEPS/TotalSpineSeg) вырезанный ROI одного диска/одной пары фасеток, то есть пайплайн кропа вам придётся написать самим, и ошибка кропа напрямую войдёт в градацию. Во-вторых, перенос на шейный/грудной отделы без дообучения не обоснован ничем: ни морфология фасеток, ни контрастные характеристики дисков между отделами не совпадают, а дообучение запрещено вашими условиями (нет разметки и нормативной когорты). В-третьих, точечные метрики качества (accuracy/AUC по пяти классам Pfirrmann на отложенном тесте того же, одноцентрового датасета) приведены в статье, но это внутренняя валидация без внешнего центра — конкретные значения здесь не привожу, так как не перепроверял их по тексту статьи в этой сессии (**не проверял**), а внешней валидации не существует [^36^]. Вывод: как калиброванный поясничный грейдер — годится; как ответ на ваш приоритетный шейно-грудной вопрос — нет.

## B. Чего в открытом доступе НЕ существует (проверено адресно)

Этот раздел — самый важный для планирования: каждый пункт ниже проверялся адресными поисками по репозиториям, HuggingFace, Grand Challenge, Mendeley Data, Zenodo и полным текстам статей, а не «по памяти». Формулировка «не существует» означает: на 22.08.2026 не найдено ни одного артефакта, одновременно (а) решающего задачу, (б) с публичными весами без запроса и (в) работающего без дообучения на ваших данных. Если какой-то из этих пробелов для вас критичен, единственный честный путь — собственная калибровка на датасетах из раздела C, что выходит за рамки inference-only сценария.

**B-1. Сегментация + градация ГРУДНЫХ фасеточных и реберно-позвоночных суставов на МРТ — не существует.** Всё, что есть по фасеточным суставам в открытом доступе, относится к одному из трёх несоответствий: (i) поясничный отдел (Nikpasand/DRUM — Fujiwara, только L1/2–L5/S1 [^36^][^46^]; Kowlagi — NFBC1966, поясн., без кода [^60^]); (ii) КТ вместо МРТ (FacetJoint — код без весов [^1^]); (iii) шейный отдел — и то только в закрытых работах. Реберно-позвоночные (costovertebral/costotransverse) суставы не встречаются как объект сегментации ни в одной открытой модели или датасете вообще — ни в SPIDER, ни в TotalSpineSeg, ни в SPINEPS (14 структур: тела, дужки, отростки, диски, канал — без реберно-позвоночных суставов [^62^][^72^]), ни в TotalSegmentator (`vertebrae_pp` делит тело/дугу/отростки, суставов нет [^6^][^39^]). Для вашего приоритетного вопроса это означает: автоматической градации грудных фасеток и реберно-позвоночных суставов на одном исследовании без обучения получить нельзя — максимум, что доступно, это геометрия из уже имеющихся у вас масок SPINEPS (задние элементы с разделением лево/право) плюс визуальная оценка.

**B-2. Детектор отёка костного мозга позвонков (BME) без дообучения — не существует.** Ближайшая по смыслу опубликованная задача — Modic-изменения: воксельная работа Gao 2022 (UCSF, 75 поясничных МРТ) кода и весов не опубликовала [^40^]; классификаторы Modic I/II встречаются в литературе, но всегда как «обучите сами на нашем описании». Датасетов с воксельной разметкой BME/Modic в открытом доступе нет (в LSMA-PQR, LSS-MRI-AISSLab и SPIDER таких меток нет — там Pfirrmann, высоты дисков, стенозы и сегментации [^54^][^79^][^27^]). Ваши корональные STIR-серии (TI 100 мс, старое грудное исследование) и миелографический SPACE по контрасту подходили бы для BME-анализа, но готовой модели, принимающей их на вход, не существует; предлагать SAM-Med3D как «детектор отёка» было бы именно тем ансамблем некалиброванных эвристик, который правилами запрещён.

**B-3. Открытые нормативные распределения геометрических/текстурных метрик для ГРУДНОГО отдела — не существуют.** Проверено по трём направлениям. (i) Единственная крупная работа с популяционными биометрическими нормативами тел позвонков/дисков/канала (Streckenbach и соавт., German National Cohort, 10 215 МРТ-исследований всего позвоночника) публикует нормативы через **закрытый инструмент** GNC — доступа к модели/весам нет, а таблицы в статье не дают машиночитаемых распределений для грудного отдела [^73^]. (ii) Опубликованные нормативы спинного мозга C1–Th12 (площадь, диаметры, компрессия) существуют, но это **когорта всего из 28 молодых азиатских взрослых** и только мозг/канал, не тела и не суставы [^49^]; нормативная база PAM50 в SCT (r20250321) — тоже про мозг/канал, не про костные структуры [^76^]. (iii) Нормативы «vertebral deformity ratios» C3–L5 существуют (1638 женщин, рентген-денситометрическая методика), но это женская когорта и не МРТ-геометрия — для калибровки МРТ-измерений грудного отдела непригодно [^58^]. Итог: любые «z-score» для грудных тел позвонков, дисков или канала в вашем отчёте будут либо самодельными (запрещено — нет нормативной когорты), либо взятыми из источников, не соответствующих модальности/популяции. Корректная формулировка в заключениях — абсолютные значения + качественная оценка, без популяционных порогов.

**B-4. (Дополнительно) Градация фораминального стеноза вне поясничного отдела — не существует.** Все открытые артефакты по фораминальному стенозу поясничные: датасет LSS-MRI-AISSLab (2979 размеченных форамен, 4 градации — но это данные, не модель [^78^][^79^]) и решения RSNA 2024 (код без весов [^17^][^22^]). Шейный фораминальный стеноз (важный для «боли при движениях шеи») в открытых моделях отсутствует полностью; грудной — тем более.

Практический вывод из таблицы 2 двойной. С одной стороны, для поясничного отдела данных теперь достаточно, чтобы обучить и откалибровать почти любую дегенеративную задачу (градация дисков, фораминальный и канальный стеноз) — проблема поясничного отдела на август 2026 г. это не данные, а отсутствие готовых весов (A-4). С другой стороны, для шейного отдела есть только CSpineSeg с DUA и только с масками тел/дисков (без стенозов, без суставов, без BME), а для грудного отдела нет **ни одного** специализированного размеченного датасета — торакальная патология присутствует лишь фрагментарно внутри whole-spine корпусов (NAKO, TotalSegmentator MRI, обучающие данные SPINEPS [^62^]). Это объективная стена: калиброванная торакальная модель в обозримом будущем может появиться только из NAKO-подобных популяционных данных, доступ к которым контролируемый.

Кураторский список awesome-spine-mri (NeuroPoly) остаётся лучшей точкой входа для мониторинга новых датасетов — он поддерживается сообществом и обновляется; рекомендую сверяться с ним раз в квартал [^61^]. Отдельно: свежий обзор 2026 г. по сегментации поясничного отдела (Mendes и соавт., Biomedical Signal Processing and Control) систематизирует, какие из «поясничных» датасетов действительно открыты, и подтверждает картину таблицы 2 [^84^].

**Инструменты и модели (появилось и реально расширяет возможности).** (1) **SCT 7.0 (25.04.2025)** — самое значимое событие периода: добавлены `sct_detect_compression` (калиброванная вероятность компрессии C3/C4–C6/C7 с внешне валидированными порогами), контраст-агностическая сегментация серого вещества и модель РС-очагов на аксиальном T2 [^23^][^24^]. (2) **SCT 7.1 (15.08.2025)** — обновление модели очагов (r20250626), tissue-bridge ratio, MSCC-метрики и привязка измерений к уровням дисков через `-discfile` — последнее напрямую стыкуется с вашей VERIDAH-нумерацией из SPINEPS [^23^]. (3) **SCT 7.2 (28.11.2025)** — `sct_compute_ascor` (пороги 36,9 %/49,3 % для шейного стеноза), режим `spine` в `sct_deepseg` на базе TotalSpineSeg, test-time augmentation, метрики симметрии/квадрантов [^23^][^69^]. (4) **SCT 7.3 (09.05.2026)** — DL-коррекция движения и длинные меры канала (length_anterior/posterior) [^23^]. (5) **Свежие веса вне номерных релизов**: канал r20260406 (06.04.2026, 1052,3 МБ) и контраст-агностическая модель мозга v4.0 (zip от 28.06.2026) — последняя ещё не входит в номерной релиз, ставится из master [^23^][^33^]. (6) **TotalSegmentator 2.5.0 (15.01.2025)** — вдвое расширена МРТ-обучающая выборка, добавлены задачи `vertebrae_mr`, `tissue_4_types`, `thigh_shoulder_muscles_mr`; 2.15.0 (01.07.2026) принёс `totalseg_spine_report`, но это КТ (остеопоротические переломы) — для вас неприменимо; 2.17.0 (29.07.2026) — `vertebrae_pp` (тело/дуга/отростки) [^6^][^39^]. Ваши установленные SPINEPS (актуально 2.0.0 от 02.06.2026) и TotalSpineSeg (актуально r20260730 от 31.07.2026, step1+step2 ≈ 2,1 ГБ) за период тоже обновились — имеет смысл подтянуть версии.

**Датасеты (появилось и открывает калибровку, если когда-нибудь снимется запрет на обучение).** (7) **Duke CSpineSeg (29.09.2025, MIDRC)** — первый крупный шейный корпус с масками тел/дисков, доступ через регистрацию+DUA [^29^]. (8) **LSS-MRI-AISSLab (v1 09.12.2025; v3 02.01.2026)** — первая открытая разметка фораминального стеноза (2979 форамен, 4 градации), поясн. отдел, со статьёй в Scientific Data 2026 [^78^][^79^]. (9) **LSMA-PQR (18.05.2026)** — 1545 градаций Pfirrmann + высоты дисков + маски на 515 пациентах [^54^]. (10) **RSNA-LSDD переиздан в AWS Open Data / MIRA RSNA** — крупнейший корпус дегенерации (>2600 исследований, 5 состояний × 5 уровней) теперь доступен по некоммерческой лицензии вне Kaggle [^86^][^89^]. Заметьте: все четыре «датасетных» события — про поясничный и шейный отделы; грудного датасета за два года не появилось вообще, что согласуется с разделом B.

## Итог: что имеет смысл добавить в ваш пайплайн прямо сейчас

С учётом всех ограничений (одно исследование, inference-only, A100 80 ГБ на Colab с медленным интернетом) реалистичное ядро добавки выглядит так: установить **SCT 7.3**, скачать три модели (контраст-агностический мозг v3.0/v4.0, канал r20260406 — 1052 МБ это основной объём трафика, серое вещество 250 МБ) и прогнать сагиттальные T2 и 3D SPACE через сегментацию мозга+канала; затем `sct_detect_compression` и `sct_compute_ascor` дадут **калиброванные** числа по шейному каналу (вероятность компрессии по Horáková-порогам 0,345/0,451 и aSCOR с порогами 36,9 %/49,3 %), а `sct_compute_compression` — PAM50-нормированную морфометрию C1–Th12 на фоне нормативной базы r20250321 [^28^][^35^][^69^][^76^]. Это закрывает из вашего списка задач: стеноз шейного канала (калиброванно) и геометрию канала/мозга грудного отдела (описательно). Нумерацию уровней для `-discfile` вы уже получаете из SPINEPS/VERIDAH и TotalSpineSeg — стыковка прямая [^23^].

Всё остальное из клинического вопроса честно остаётся за пределами открытого доступа: грудные фасеточные и реберно-позвоночные суставы, BME, торакальные нормативы и фораминальный стеноз вне поясницы — готовых моделей нет (раздел B), и предлагать вместо них promptable-сегментацию или VLM-«второе мнение» было бы именно тем ансамблем некалиброванных эвристик, который вы обоснованно запретили. Поясничный грейдер с DRUM (Pfirrmann/Fujiwara) можно держать как опцию на случай, если поясничный отдел всё же понадобится: веса проверены, лицензия CC BY-NC-ND, но потребуется свой кроппинг ROI по маскам [^36^][^46^]. Мониторинг новых поступлений разумно вести по awesome-spine-mri и релизам SCT/TotalSegmentator — судя по динамике 2025–2026 гг. (рисунок 1), следующие практически значимые события с наибольшей вероятностью придут именно из этих двух экосистем [^61^].
